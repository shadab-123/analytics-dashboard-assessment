# MapUp - Analytics Dashboard Assessment

## Overview

This project is part of the MapUp Analytics Dashboard Assessment. It involves analyzing the Electric Vehicle (EV) Population dataset and creating a frontend dashboard that provides key insights and visualizations about the data. The dashboard is designed to be interactive, user-friendly, and responsive, showcasing trends and relationships effectively.

## Live Dashboard

The live version of the dashboard is deployed and accessible at:  
**[Electric Vehicle Dashboard](https://analytics-dashboard-assessment-mu-seven.vercel.app/)**

## Features

### 1. Key Metrics Section
- Displays the total number of Electric Vehicles (EVs) in the dataset.
- Highlights the top EV manufacturer based on the number of vehicles.
- Shows the average electric range of vehicles.

### 2. Charts and Visualizations
- **Bar Charts:**
  - Distribution of Electric Vehicle Types.
  - Distribution of Vehicle Models.
  - EV registrations by year.
- **Pie Chart:**
  - Top EV manufacturers.
- **Line Charts:**
  - Electric range distribution.
  - EV sales by country.

### 3. Data Table
- Tabular representation of EV population data with multiple columns for:
  - City
  - Model Year
  - Make
  - Electric Range

## Dataset

The dataset used for this assessment is sourced from the Kaggle dataset:  
**[Electric Vehicle Population Data](https://www.kaggle.com/datasets/willianoliveiragibin/electric-vehicle-population)**

A reduced version of the dataset is provided for efficient frontend usage. It includes key information such as vehicle make, model year, range, and more.
